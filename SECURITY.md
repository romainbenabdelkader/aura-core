# Security Policy

aura-core is a reference implementation of cryptographic primitives, not a
production system.

If you find a security issue — especially in the cryptographic usage
(hashing, canonicalization, Ed25519 signing/verification) — please report it
privately to the maintainer rather than opening a public issue, to allow
responsible disclosure.

Do not include sensitive material (private keys, real signatures) in reports
or test cases.
